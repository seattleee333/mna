# 로그인(구글·카카오·네이버) + 구글시트 회원 저장 설정

코드는 이미 들어가 있어요. 아래 **키 4개만 발급해서 `config.js`에 넣으면** 로그인이 켜지고, 그 전까지는 로그인 없이 열려 있어요(사이트가 잠기지 않도록).

## 1. 구글시트 + Apps Script (회원 데이터 저장소)
1. 새 구글시트를 만들고 이름을 `ALL ABOUT M&A 회원` 으로 저장
2. 메뉴 **확장 프로그램 → Apps Script** → `apps-script/Code.gs` 내용을 통째로 붙여넣기 → 저장
3. 왼쪽 **프로젝트 설정 → 스크립트 속성**에 아래 값을 추가(아래 2~4번에서 발급)
   `GOOGLE_CLIENT_ID`, `KAKAO_REST_KEY`, `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (카카오 보안 사용 시 `KAKAO_CLIENT_SECRET`)
4. **배포 → 새 배포 → 웹 앱**: 실행 사용자 `나`, 액세스 권한 `모든 사용자` → 배포 → 나오는 `…/exec` 주소를 `config.js`의 `appsScriptUrl` 에 입력
   (처음 배포 때 권한 승인 창이 뜨면 허용)

## 2. 구글 로그인
Google Cloud Console → API 및 서비스 → 사용자 인증 정보 → **OAuth 클라이언트 ID(웹 애플리케이션)** 생성
- 승인된 JavaScript 원본: `https://seattleee333.github.io`
- 발급된 클라이언트 ID → `config.js`의 `googleClientId` + Apps Script 속성 `GOOGLE_CLIENT_ID`

## 3. 카카오 로그인
developers.kakao.com → 애플리케이션 추가 → 카카오 로그인 **활성화**
- Redirect URI: `https://seattleee333.github.io/mna/login.html`
- 동의항목: 닉네임, 카카오계정(이메일)
- **REST API 키** → `config.js`의 `kakaoRestKey` + Apps Script 속성 `KAKAO_REST_KEY`

## 4. 네이버 로그인
developers.naver.com → 애플리케이션 등록 → 사용 API **네이버 로그인**(이름·이메일 필수)
- 서비스 URL: `https://seattleee333.github.io/mna/`
- Callback URL: `https://seattleee333.github.io/mna/login.html`
- Client ID → `config.js`의 `naverClientId` + Apps Script 속성 `NAVER_CLIENT_ID`
- Client Secret → **Apps Script 속성 `NAVER_CLIENT_SECRET` 에만** (GitHub에 올리지 마세요)

## 참고
- 비밀값(secret)은 Apps Script 속성에만 저장돼요. `config.js`에는 공개돼도 되는 ID/키만 들어갑니다.
- 회원 정보는 시트의 `회원` 탭에 쌓여요: 가입일시, 최근로그인, 로그인횟수, 로그인방식, 소셜고유번호, 이름, 이메일, 동의여부.
- 현재 '로그인 필요'는 화면 단위 보호예요. 설문 계산은 브라우저에서만 이뤄지고 서버에 입력값이 가지 않아요. 유료 서비스(AI 매칭 결제)가 붙을 때는 서버 쪽 검증을 추가해야 해요.
- 시트에는 개인정보가 쌓이므로 시트 공유 범위를 본인(필요 시 담당자)으로 제한하고, 개인정보처리방침 페이지를 꼭 만들어 주세요.
